## архитектура сайта

**сайт вкллючает в себя следующие страницы:**
-`шапка сайта` - располагает в себе навигацию и название сайта.
-`направления` - список основных стилей тату для небольшого ознакомления.
-`выбор стиля` -главные советы для выбора тату.
-`выбор мастера`- советы о том, на что в первую очередь стоит обратить внимание при выборе мастера.
-`Запись`-место для ввода контактных данных для записи к мастеру.

## исполльзуемыем технологии

1. `HTML5`
2. `CSS3`
3. `JavaScript Vanilla`
